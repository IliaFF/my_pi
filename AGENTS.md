# Проект my_pi

## Сборка Pi

Исходники сборки, скрипты и проверки лежат в корне репозитория; OpenSpec и CI в этой сборке не используются. Порядок работы: правка кода, затем `node scripts/<тест>.mjs` до PASS, review diff, запись evidence, commit. Установленный `~/.pi/agent` не править вместо Git-источника. Не менять production и не публиковать репозиторий без отдельного согласования.

## Маршрутизация DeepSeek

Порядок апстримов задаётся явно по цене кеш-чтения: `scripts/openrouter-cache-order.mjs` пересобирает `compat.openRouterRouting`, `cost` и `maxTokens` модели `deepseek/deepseek-v4.1-flash-1017` в `~/.pi/agent/models.json` (`allow_fallbacks: false`, `quantizations: ["fp8"]`, цены учёта — от первого провайдера списка). Обновление точечное: остальные поля `compat` и `cost` сохраняются. Запрос к OpenRouter идёт с таймаутом 20 с, запись защищена lock-файлом `models.json.lock` (устаревание 5 минут), временный файл уникален по pid; юнит ограничен `TimeoutStartSec=120`. В список попадают только апстримы с `quantization: fp8`, без flex/priority/spot-тиров и без слагов из `BROKEN_TAGS` (сейчас `stepfun/fp8`: отдаёт 400 `input_invalid` на наборе инструментов `read/bash/edit/write/codemode`). `maxTokens` переопределяется в 65536, чтобы фильтр контекста OpenRouter не резал никого; каталожные 943718 отбрасывали все fp8-апстримы и запрос падал с 404. Обновление — systemd user таймер `openrouter-cache-order.timer` раз в час (`configs/systemd/`), ручной прогон — `node scripts/openrouter-cache-order.mjs`, проверка без записи — `--dry-run`.

Отказ маршрута (ни один провайдер из `order` не доступен) — остановиться, показать ошибку и спросить пользователя, переходить ли на дефолтный роутинг OpenRouter. Порядок вручную не править.

Команда `/providers` глобального расширения `extensions/providers/index.ts` при каждом вызове запрашивает актуальные `/endpoints` текущей OpenRouter-модели с авторизацией через ModelRegistry: цены USD/M, throughput_last_30m.p50 (токенов/с за 30 минут) и настроенный маршрут из активного объекта модели. По умолчанию выводит таблицу топ 10 по цене кеша (маршрут и подходящие fp8); `/providers all` показывает всех, включая исключённых, с колонкой типа. Карточки выводятся через custom entry, не участвуют в LLM-контексте и не меняют настройки. «Основной» обозначает первый настроенный слаг, а не доказанного исполнителя последнего запроса. После изменения models.json применить модель к текущей сессии: `/model`, дождаться обновления и повторно подтвердить выбор.
