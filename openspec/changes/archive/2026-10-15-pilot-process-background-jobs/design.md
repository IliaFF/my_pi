# Design

Reuse package process lane, not a new manager. Upstream PI_BG_FEATURES=process alone does not forbid isAgent:true or automatic wake through bg_run/EventBus, and defaults enable every lane. Enforce limits at the shared registry startTask boundary, not in one caller. Patch only shipped dist JS, exact version/hash gated and pristine tarball replay tested. Restrict feature parser to process; schema/prompt/defaults declare isAgent:false and notification-only; event capabilities match. Never load anthropic-attribution entry. No update network check; no auto-added model children or routes.

Local shell command retains full user permissions and can itself call remote/network/model programs; this is not sandboxing. Keep explicit surviveReload opt-in with upstream same-process ownership; restart/crash survival not claimed. Default finite task timeout 600s, fixed per-task output cap 1MiB for pilot; log reads stay bounded. Finished project logs need explicit cleanup, not silent deletion; total cross-session storage quota deferred and disclosed. Do not edit tested code while checks run; a test result proves its captured scope only.

Real SDK test runs no provider prompts, registers no credentials, blocks fetch. Exercise source entry with temporary HOME/agent/workspace, actual shell commands and native reload; provider registration/model auto-wake forbidden. Test tree kill on Linux, timeout, output cap, exact identity on reload, failure exits and disposal/restart termination. Existing entire npm gate stays mandatory. Preserve old locks/versions/settings and validate backup before runtime. If isolated behavior fails, do not install into runtime or build a replacement silently.
