# Design

Сохранить существующий английский tool description и добавить короткое предупреждение сразу после инструкции check. Снимок охватывает весь Git worktree либо каталог с предусмотренными исключениями, а не только diff. Отказ на symlink/submodule/unsupported file является текущим контрактом fingerprint. Ручной evidence не отменяет записанный failed preflight. Существующее явное supersede доказуемо не запущенного preflight остаётся доступным; предупреждение запрещает менять scope только ради обхода, а не обоснованную замену проверки.

Изменение не добавляет runtime-ветвлений, поэтому failing regression не требуется. Проверка: review точного текста и полный существующий npm test, включая actual SDK tests.
