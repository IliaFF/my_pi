## Context

`findTodoPath()` ограничивает поиск ближайшим Git worktree и не создаёт файлов; `core.ts` знает ровно четыре латинских заголовка и строки `- [ ]`. Оба ограничения оказались слишком узкими на реальных проектах пользователя: живые пункты в `## Ожидает` обычными `-` невидимы, а проект без Git теряет очередь при запуске из подкаталога.

## Goals / Non-Goals

Цели: распознавать уже существующие файлы без переписывания; дать очереди появиться там, где её нет; сохранить строгость для истории (`Completed`) и не читать чужие очереди.

Не входит: новые настройки и зависимости, эвристики «похоже на задачу» за пределами активных разделов, миграция существующих файлов, установка в runtime.

## Decisions

1. **Маркер корня — `.git` или `AGENTS.md`, ближайший вверх.** `AGENTS.md` — уже действующее соглашение проекта в Pi и в этих репозиториях. Поиск останавливается на первом маркере, поэтому вложенный Git-репозиторий по-прежнему не наследует внешнюю очередь. Каталог без маркеров сохраняет прежнюю границу — стартовый каталог.
2. **Создание в корне, а не в стартовом каталоге.** Иначе запуск из подкаталога создаёт второй файл-очередь рядом с настоящим. Исключения — `$HOME`, `/`, `/tmp`: там маркерных проектов нет, и файл был бы мусором.
3. **Создание только через пишущих потребителей.** Панель и `/queue`/`task_queue` вызывают `ensureTodoPath()`; `start_task_session` остаётся на `findTodoPath()`, чтобы handoff не создавал файлы. Запись идёт с `flag: "wx"`, существующий файл не перезаписывается, `EEXIST` считается успехом.
4. **Слияние групп разделов, а не расширение регэкспа.** Раздел становится группой строк: `## Ожидает` + `## Pending` — один логический Pending. Вставка идёт в латинский заголовок, если он есть, иначе в первый заголовок группы; повтор одного написания остаётся ошибкой, иначе два `## Pending` молча удвоили бы очередь.
5. **Обычные `-` только в активных разделах.** Исторические списки в `Completed`, «История проверок» и любые другие разделы остаются вне очереди. Цена: при `claim`/`complete` обычный пункт перезаписывается как `- [ ]`/`- [x]` — текст и порядок сохраняются.
6. **Пустая очередь по-прежнему скрывает панель.** Пользователь выбрал это явно; автосозданный файл не появляется в интерфейсе, пока в нём нет активных задач.

## Risks / Trade-offs

- `AGENTS.md` выше по дереву (например, в общем каталоге работ) расширит область поиска очереди. Смягчение: только первый маркер и только до него; вложенный `.git` остаётся сильнее.
- Автосоздание может положить `TODO.md` в каталог, который пользователь проектом не считает; защита — три исключённых пути и отсутствие создание в недоверенных/headless сессиях.
- Слияние групп меняет поведение ошибки на дубликаты: одинаковое написание падает, разное — нет. Тест «duplicate managed sections» это фиксирует.
- Обычные пункты в активных разделах могут быть восприняты как задачи, если пользователь держит там прозу списком. Это осознанный выбор; `Completed` не затронут.
