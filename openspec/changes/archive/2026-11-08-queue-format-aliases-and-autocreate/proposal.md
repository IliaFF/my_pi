## Why

Очередь читает только латинские заголовки `## In progress/Pending/Blocked/Completed` и чекбоксы `- [ ]`. В проекте `YSDA_HWs/ML1` четыре живых пункта лежат в `## Ожидает` обычными `-`, поэтому панель показывает два пункта вместо шести и молча теряет остальные; в `search_agent` единственный незакрытый пункт стоит под `# Задачи` вне разделов. Отличить «очередь пуста» от «очередь не распознана» в интерфейсе нельзя.

Дополнительно: сессия в проекте без `TODO.md` не имеет очереди вообще, а запуск из подкаталога проекта без Git не находит родительский `TODO.md`, потому что граница поиска привязана только к `.git`. Панель в таких случаях исчезает без сообщения, что выглядит как поломка расширения.

## What Changes

- Раздел распознаётся по латинскому заголовку или по псевдониму: «В работе» → In progress, «Ожидает» → Pending, «Блокировано» → Blocked, «Завершено» → Completed.
- Обычный пункт `- текст` считается незакрытой задачей только в активных разделах (In progress, Pending, Blocked) и их псевдонимах. В Completed по-прежнему засчитывается только `- [x]`, чтобы исторические списки не попадали в очередь.
- Повтор одинакового написания заголовка остаётся ошибкой. Разные написания одного логического раздела объединяются в одну группу; вставка новой задачи идёт в латинский заголовок, если он есть, иначе в первый заголовок группы.
- Корень проекта для поиска очереди — ближайший вверх каталог с `.git` или `AGENTS.md`; без такого маркера — стартовый каталог. Раньше учитывался только `.git`.
- Если в диапазоне от стартового каталога до корня `TODO.md` нет, создаётся заготовка `# TODO` с четырьмя пустыми разделами в корне проекта. Создание не выполняется в `$HOME`, `/` и `/tmp`.
- Создание выполняется только в доверенной TUI-сессии; `/queue` и `task_queue` пишут через тот же resolver, `start_task_session` остаётся read-only.
- **BREAKING** для проектов без Git: очередь в родительском каталоге с `AGENTS.md` теперь видна из подкаталогов. Проект без `.git` и без `AGENTS.md` сохраняет прежнее ограничение стартовым каталогом.

## Capabilities

### Modified Capabilities

- `task-selection`: распознавание формата задачи/раздела, границы поиска очереди и создание отсутствующей очереди.

## Impact

- `local-extensions/todo-queue/core.ts` (разбор разделов и задач), `store.ts` (корень проекта и создание `TODO.md`), `panel.ts` и `index.ts` (общий resolver), `README.md`.
- `scripts/test-todo-queue.mjs` (unit) и `scripts/test-todo-queue-sdk.mjs` (настоящий SDK, панель, tool/slash).
- Вне объёма: новые настройки, зависимости, эвристики для `Completed`, установка в `~/.pi/agent`, публикация.
