## ADDED Requirements

### Requirement: Actual Herdr characterization stays isolated
Integration tests MUST use private HOME, XDG directories, Herdr sockets and plugin registry, with no inherited caller Herdr routing or credentials. They MUST use the pinned candidate and synthetic local responses only. They MUST NOT activate production packages, change caller panes or views, or launch paid/cloud model work. Cleanup MUST verify ownership and retain uncertain residue.

#### Scenario: Private test server
- **WHEN** Focus, All or child launch is exercised
- **THEN** only the explicitly created lab servers and profiles receive commands

### Requirement: Evidence covers child context and sidebar separately
Evidence MUST distinguish actual Pi process/profile inheritance, context tools across compaction, result delivery, persistent lifecycle and rendered sidebar behavior from mock assertions. It MUST report blockers and not claim autonomous multi-window reasoning from scripted responses.

#### Scenario: Rendered sidebar filtering
- **WHEN** the plugin runs Focus and All on the installed Herdr build
- **THEN** evidence checks rendered visibility and safe treatment of blocked/unknown children, or records the unavailable scenario without claiming success

#### Scenario: Child context continuity
- **WHEN** an actual child runs across synthetic context cycles
- **THEN** evidence checks active context tools, persisted compaction entries and bounded result delivery separately from model reasoning
