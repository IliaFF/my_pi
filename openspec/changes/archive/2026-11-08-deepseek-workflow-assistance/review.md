# Review внедрения

Изменение добавляет помощь по каталогу скиллов, рекомендации codemode, evidence-based review и приватные метаданные для DeepSeek. По умолчанию другие семейства моделей не вызывают classifier и не получают assistance section. Проверялась работа нескольких последовательных сессий одного пользователя, а не многопользовательский сервис.

Применён ponytail-review: проверены полный tracked diff, новые workflow/privacy/SDK-check файлы, callers, installer/rollback, manifest и обязательный runner. Независимого рецензента не было; исходники и проверки доступны автору реализации.

## Исправленные существенные дефекты

1. `context` не содержал system messages: после смены модели оставался ранее подгруженный скилл. Настоящий SDK-тест воспроизвёл дефект; обработчик перенесён в `context_with_system`.
2. Первое system message не обязательно имеет index 0 после восстановления ветки: найдена и исправлена эта предпосылка. SDK-проверка off/auto + restore проходит.
3. Бюджет контекста не учитывал заголовки и omission metadata. Граничная регрессия воспроизвела 98728 байт вместо максимум 98304; подсчёт теперь включает полные блоки и ограниченный резерв omission.
4. Недоверенный project skill из родительского каталога обходил проверку cwd. Теперь учитывается SDK sourceInfo.scope; failing regression подтверждён.
5. Redaction сериализованной JSON-строки ломала синтаксис при query token. Теперь значения и ключи редактируются до сериализации; проверяются parse, отсутствие маркеров, permissions и rotation.
6. Catalog description могла содержать известный env credential. Failing regression подтверждён; текст routing question теперь проходит redaction.
7. Python tar data filter удалял group-write при rollback. Полный gate на Linux выявил изменение 0664 -> 0644; отдельная явная regression fixture и восстановление обычных mode bits исправили root cause. Специальные биты не восстанавливаются, проверки путей/ссылок сохранены.
8. Извлечение абзацев неверно считало строки после нескольких пустых строк. Разделители теперь участвуют в подсчёте строк; failing regression подтверждён.

## Результат

После исправлений нерешённых обязательных findings в рассмотренном scope не обнаружено. Установка допустима только после окончательной валидации того же состава исходников, backup и проверки установленной копии. Объём реализации не доказывает live улучшение: оценки Jev могут ошибаться, routing добавляет latency и стоимость; explicit on применим и к другим моделям.

Не проверено: live OpenRouter availability/качество/latency, внешние MCP transports, OS-level sandbox. Compaction использует штатный SDK summary на фиктивном chat provider; workflow при этом не вызывает classifier. Remote npm gate r2 прошёл 29/29, source manifest 649 файлов совпал до и после прогона. Последующие документационные/archive изменения требуют финальной сверки и gate. Python autopep8/Ruff отсутствуют; новые зависимости ради них не добавлялись. CI для нового commit ещё не запускался.
