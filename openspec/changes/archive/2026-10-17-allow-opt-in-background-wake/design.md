# Design
Modify the existing version-gated dist patch only. At shared startTask reject agents as before, validate completion wake as boolean, require notifications for explicit wake, and preserve explicit true while defaulting to false. EventBus advertises support and retains its existing boolean validation. Tool schema accepts a boolean and its descriptions/guidelines distinguish default notification-only from authorized opt-in. `/bg` remains notification-only. Keep finite600s deadline,1MiB per-task cap and bounded reads unchanged. Do not add delegates, routes, environment switches or another manager.

Upstream already sends a durable completion through Pi.sendMessage with followUp and triggerTurn, and guards duplicate notification. Reuse it, including opt-in killed-task completion; shutdown must suppress wake. Same-process reload may preserve opted ordinary jobs and their requested completion policy; quit/restart do not adopt historical jobs. A wake requests a model turn, not permission for deployment/retries/paid operations. For remote services, launch command completion is not service completion; no SSH watcher is in scope.

Extend the existing actual SDK fixture with scripted faux responses and no credentials/network. Verify idle success and failure, explicit cancel, queued busy continuation, no duplicate on status/log reads, notification-only defaults, tool/EventBus acceptance and rejection, native reload and shutdown suppression. Use gates instead of timing assumptions for busy/reload. Before code changes the positive regression must fail on the old shared wake guard. Keep all existing lifecycle/security checks. A passing faux SDK turn is not proof of provider/UI availability.

Local activation after source gate: create private hash-verified backup, update only the approved compiled package files and owned maintenance payloads, preserve unrelated package/config/auth bytes and active session. Verify package replay plus host gate and native SDK test. Never apply the entire unpublished Git history or reinstall unrelated packages; no GitHub/VPS deployment. User must reload/restart explicitly.
