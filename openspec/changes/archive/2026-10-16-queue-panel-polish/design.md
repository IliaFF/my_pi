# Design

Independently implement presentation ideas seen in MIT rpiv-mono revision 1ffa165; no upstream source copied. Keep our file-backed queue, parser and generation/revision watcher guards. Formatter orders current, Pending FIFO, then Blocked, with distinct text glyphs as well as colors. Header counts all Pending/Blocked, never historical Completed. Exact hidden count includes every omitted unfinished row. Last tree branch closes cleanly; an overflow row replaces the last available task slot when needed.

Native widget render reads an immutable parsed snapshot captured by a validated refresh. Formatting, color and width clipping happen in render so resize and getToolsExpanded changes need no disk access/watcher tick. Preview budget is min(6, half terminal rows), expanded budget is half terminal rows, minimum one row. Collapse still wins over global expansion and occupies one row. Default six-row formatting remains usable in pure tests. Generic read error stays safe and missing file stays hidden. No full-screen overlay, pager, config, dependencies, second task cache/store, recently-completed persistence or per-session progress counters.

Ctrl+Shift+T delegates to the same toggle as the slash command. Existing registration/runtime resolution owns conflicts; source/project and configured bindings are checked before adding it. The slash command remains the fallback for terminals without distinguishable modifier reporting. Current row uses warning glyph/accent bold text; Pending is neutral with dim glyph, Blocked uses warning; meaning survives monochrome. Long titles are clipped with the native ellipsis, full text remains in /queue.

Keep telemetry evaluation separate from implementation: inspect dispatcher/provider/instrumentation and compare existing loop-profiler. Characterize pure code with synthetic data and isolated dependency stubs where needed; explicitly distinguish that from actual installed SDK/MLflow validation. No private sessions or real provider requests.
