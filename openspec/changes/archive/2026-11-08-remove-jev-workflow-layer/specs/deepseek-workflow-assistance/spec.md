## REMOVED Requirements

### Requirement: Automatic assistance is model scoped
**Reason**: Пользователь потребовал откат контура: A/B дало 0/4 загрузок стайлгайда против 4/4 без расширения, а гидратация переписывала головное system-сообщение каждый запрос и инвалидировала весь prompt cache.
**Migration**: Автоматической активации по модели нет; модель и провайдер выбираются штатно.
