## Decisions
Status delivery remains best-effort: handle a synchronous net.createConnection throw as a rejected request inside the shared async sendRequest boundary. Keep normal false-result retry and no disable flag. The mandatory gate already uses an environment allowlist excluding HERDR_ENV/HERDR_SOCKET_PATH/HERDR_PANE_ID, and is retained. The dedicated native SDK test deliberately injects TUI mode and a blocked transport on actual SDK events and observes no unhandled rejection, native error or real IPC. NETWORK_BLOCKED remains fail-closed for unrelated test network attempts. Historical reports are evidence, not garbage to delete; exact original guard-preload origin is not established by the stack alone.

Installer restore must validate the same exact managed path set, including task-session, without accepting arbitrary new destinations. Validate member/link paths against this set, reject special types and absolute/escaping links, and extract into a private temporary stage using standard tarfile data_filter. Stage and verify all expected present paths before deleting any current managed destination. Move only named managed paths back, leaving shared parent permissions/private files alone. Relative npm .bin links are allowed only within managed trees. Staging creates transient disk data even on dry-run; no agent file changes. Reject an existing destination ancestor escaping agent root. Restore tests use temporary fake runtimes; production restore is never exercised.

Lock remediation stays within @modelcontextprotocol/sdk's declared Hono range; review lock diff and reject unrelated updates. Audit zero means no known advisory at inspection time, not proof of service security or use of vulnerable serveStatic. User's scientific/history issues are not changed by this fix.

Current task remains in progress. The older Blocked row is reconciled using supported task_queue edit with source ancestry, identical installed audit artifact and published head evidence. Its work is complete, but current-id guards reject checks/supersede/complete for a different Blocked task and no reopen API exists. Preserve that technical blocker rather than manually moving the row or fabricating ledger results. Root TODO is authoritative; no pending reorder or second task claim occurs.
