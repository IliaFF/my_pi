## ADDED Requirements

### Requirement: Permanent policy preserves the advance delegation decision
Permanent prompt MUST assess remaining work in advance after folding, recall and compaction, not file size or duration, without waiting for overflow. Only self-contained independent tasks forecast to require more than one managed window qualify. Small scouts/prototypes stay with the parent. Unclear user intent MUST be clarified.

#### Scenario: Research method is unknown
- **WHEN** intent is clear but the solution requires independent research forecast beyond one managed window
- **THEN** unknown method alone does not prohibit delegation, and threshold, boundaries, verification and launch authorization still apply

### Requirement: Permanent policy preserves delegation responsibility
Permanent prompt MUST require executors to preserve goal, constraints, progress/evidence across context cycles; persistence alone is not proof. Results MUST be bounded summaries/checks/artifacts; the parent MUST inspect, verify and integrate.

#### Scenario: Lifecycle tools are deferred
- **WHEN** no Herdr tool schema has been loaded
- **THEN** eligibility, authorization, process-only prohibition, native handoff, no-polling and parent responsibility remain explicit in the permanent prompt
