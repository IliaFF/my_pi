## Decisions
Use action=supersede with task id, checkId, replacementId and nonempty reason. Replacement is an actually completed, current snapshot check, same task text and cwd. Only previously stable successful checks are eligible; failure requires same-command rerun. Keep append-only records, supersededBy/reason fields, and follow bounded chains to a fresh latest terminal record. Reject cycles, missing links, running/failed/unknown/invalidated/foreign records and stale replacements. Ordinary completion still requires all unsuperseded latest command/cwd checks, and any running own check blocks completion. No direct evidence bypass.

WireBlock has no message-origin metadata; changing Pi normalization/API is out of scope. The vendor patch recognizes only the full owned restore opening and strict queue prompt framing, not broad keywords or arbitrary bracketed messages. Queue task body becomes its first-line intent; plain user messages are unchanged. shortcut: exact owned text framing can misclassify a user literally reproducing that envelope; switch to origin metadata if the bridge exposes it. Both extractIndex and extractCompactionIndex use the same helper. No instruction or transcript is deleted; only derived index fields change.

Keep multiline constraint truncation as an explicit tested limitation, not a new negation parser. Snapshot finalization uses one unchanged gate command (npm test) across phases, so installed old queue can close this task without a runtime hot patch. The previously blocked task is not rewritten or forced complete through the old ledger.

## Validation
Failing regressions before code; unit identity/link/failure matrix; actual SDK archive/replacement flow, invalid cases keep TODO unchanged and do not launch shell/model/network; soft and hard index fixtures and actual SDK summary in both extension orders. Full npm test, patch apply/verify, strict OpenSpec, diff/privacy review. Archive then final committed npm test and push; root TODO records publication evidence. No personal runtime deployment.
