## Context
Основа: чистый source f4318b0843c59e12ca14f0cbfd0de38e7e1067c5. Существующие npm/package.json, configs/AGENTS.md и docs/portable-stack.md задают фактические pins и policy.

## Goals / Non-Goals
Исправить документацию без изменения поведения. Не обновлять зависимости и не устанавливать runtime. Первоначальный запрет публикации снят отдельным указанием пользователя: после PASS сделать push README и обязательных документов change.

## Decisions
Сохранить историческое CI evidence с явной привязкой к старому SHA; убрать привязанное к прошлому процессу требование restart. Обозначить Herdr как отдельный backend, а старую проверку plugin как историческую. Дать clone-команду перед cd my_pi. Regression test не нужен: программной ошибки нет, ручная сверка утверждений и существующий полный gate достаточны.

## Risks / Trade-offs
Offline gate не доказывает live работоспособность. Новые утверждения о текущем CI и установленном runtime не добавляются.
