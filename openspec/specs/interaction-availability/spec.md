# interaction-availability Specification

## Purpose
Согласовать доступность интерактивных инструментов с реальными возможностями клиента уже до первого запроса, не меняя соседние инструменты.

## Requirements

### Requirement: UI-only tool доступен только при наличии UI
Сборка MUST исключать интерактивный инструмент вопросов из активных tools при отсутствии UI уже на старте сессии. При появлении UI она MUST восстанавливать инструмент, не изменяя доступность соседних tools.

#### Scenario: Первый turn без UI
- **WHEN** сессия стартует в клиенте без UI
- **THEN** инструмент вопросов исключён до первого turn и не рекламируется модели

#### Scenario: UI появился позже
- **WHEN** перед следующим turn клиент сообщает доступный UI
- **THEN** инструмент вопросов возвращается в активные tools
